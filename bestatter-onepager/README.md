# Bestatter-Kooperation – Onepager (PDF)

Einseitige Info für Bestatter (Anhang zur E-Mail, Beilage zum Brief, Leave-behind beim Termin).

- `Bestatter-Kooperation-Sterbegeld.pdf` – fertiges PDF (A4)
- `onepager.html` – Quelle; nutzt die Schriften aus `../sterbegeld/assets/fonts/`
- `build-pdf.cjs` – erzeugt das PDF neu: `node bestatter-onepager/build-pdf.cjs` (benötigt Playwright mit Chromium)

Vor dem Versand Telefonnummer und E-Mail in `onepager.html` eintragen (mit `TODO` markiert) und das PDF neu erzeugen.
