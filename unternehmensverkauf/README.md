# M&A-Beratung – Unternehmensverkauf & Wertsteigerung

Statische, responsive One-Page-Website nach dem Design-Entwurf `Main.dc.html`
(Farben, Schriften, Abstände übernommen). Kein Build-Schritt nötig: Ordner hochladen, fertig.

| Datei | Inhalt |
| --- | --- |
| `index.html` | Startseite: Hero, Leistungen (Beratung + Verkauf), Optimierung vor dem Verkauf, Kaufpreis-Rechenbeispiel, Ablauf, Über mich, FAQ, Kontakt |
| `impressum.html`, `datenschutz.html` | Rechtliche Seiten (Platzhalter) |
| `assets/css/style.css` | Gestaltung, Farben als Variablen in `:root` |
| `assets/js/main.js` | Kontaktformular (öffnet das E-Mail-Programm) und Kaufpreis-Rechenbeispiel |
| `assets/fonts/` | Fraunces, Archivo, IBM Plex Mono – lokal, ohne Google-Server |

## Vor dem Livegang ergänzen

- Nachname (`Kai [Nachname]` in allen drei HTML-Dateien)
- E-Mail und Telefon im Kontaktbereich von `index.html`
- `CONTACT_EMAIL` in `assets/js/main.js` setzen, damit das Formular aktiv wird
- Portraitfoto (Platzhalter im Abschnitt „Über mich“)
- Impressum und Datenschutzerklärung vollständig ausfüllen / prüfen lassen
